Пользователю достаточно одного EXE: необходимые пакеты скачиваются

Исходники остаются локально и не публикуются.

## Использование

1. Запустите EXE и выберите Neverlose либо GameSense.
2. Выберите установленный Steam App 4465480 либо 730 с beta `csgo_legacy`.
3. Подтвердите, что другой чит не загружен, и нажмите запуск.

Loader скачивает актуальный пакет и проверяет размеры, SHA256 и формат PE.
Файлы хранятся в `%LOCALAPPDATA%\MicrowaveLoader\packages`.
При обновлении EXE сохраняется резервная копия, затем Loader перезапускается.
После перезапуска снова выберите нужный режим и нажмите запуск.

Neverlose: сервер и две DLL. GameSense: отдельная DLL без сервера Neverlose.
Современный CS2 не поддерживается. Не смешивайте два чита в одной сессии.
После ошибки загрузки полностью перезапустите игру.

Для приватного запуска без VAC нужны параметры Steam:

```text
-insecure -allow_third_party_software
```

## Исправление GameSense

В версии 2026.10.14.2 исправлен краш из-за изменения таблицы методов Steam
Overlay. 14 октября 2026 владелец проверил исправленную DLL в игре и подтвердил
рабочий запуск без краша. Изолированные тесты Loader проведены отдельно.
Подтверждение относится к этой проверенной конфигурации.

Поддерживаются проверенные профили Overlay `11.12.30.07` и `10.96.30.42`.
При неизвестном профиле инициализация останавливается; журнал
`skeet-crash-fix.log` создаётся рядом с загруженной DLL.
